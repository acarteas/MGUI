This audit implements `mgui-jpa.3.2` against the control inventory in `render-caching-design.md`. `MGInteractiveVisualStateTests` exercises semantic changes followed by equal-value assignments. `InteractiveControlNativeTests` uses a genuine MonoGame DesktopGL device to compare direct and capture pixels for 15 interactive states plus late modal transitions and nested cached-brush invalidation. Existing `MGButtonPressedContentOffsetTests` retain command/repeat/input/layout regression coverage.

`EveryInteractiveBrushSlotTracksMutationAndDetachesReplacedSource` and `BorderAndStateBrushSlotsTrackAllInteractiveLocalSources` exercise fill/border/state replacement and nested mutations. `UnobservedInteractiveControlsAndExplicitPaintRefreshStayLazy` proves unused controls do not discover control resource graphs; repeated observed snapshots and equal values do not rediscover them. Only semantic setter paths invalidate; no blanket `PropertyChanged` observer was added.

`MGElement.EnumerateControlRenderSources()` supplies local paint inputs to the existing `BaseRenderSourceDependencies` observer. The graph is allocated on explicit observation/registration, then refreshed on resource replacement or explicit invalidation. T18 can register once with `EnableRenderSourceTracking()` and read the maintained aggregate; it must combine the public user flag with `IsBuiltInRenderVolatile`. Clearing `IsRenderVolatile` cannot suppress intrinsic running volatility. Relevant running/value changes emit semantic revision notifications, while normal input/update callbacks continue regardless of cache eligibility.

`InvalidateVisual()` is an explicit paint/source escape hatch. It reconciles contributing membership, invokes paint-only refresh hooks, refreshes already-observed source graphs throughout that subtree, and dirties generations with a shared stamp. It does not activate previously unused source trackers or invalidate measurements. `ExplicitAncestorInvalidationRefreshesObservedDescendantRawSourceGraphs` proves adding/removing an unsupported animated source through a raw descendant collection updates eligibility facts before reuse. `ExplicitAncestorInvalidationAdvancesStaticDescendantAndAncestorOnce` proves a static-to-static edit advances both observations once; native `ancestor-invalidates-child-cached-brush` verifies immediate fallback and next-observed-generation pixel parity for a nested cached brush.

For picker raw collections, same-count color/index paint edits require `InvalidateVisual()` before drawing and refresh the existing single-selection preview. Raw logical changes that require row-count, membership, selection-label visibility or layout reconciliation must use the supported `Colors`/`SelectedColorIndexes` APIs instead. Explicit invalidation does not change collapsed label state or infer layout from raw edits. Custom timer/stopwatch converters with captured external state similarly require explicit invalidation before drawing (or a volatile owner); paint-only reevaluation preserves existing measurements, so layout-affecting formatting changes should use the supported formatting/value APIs.

Validation: Release current-source focused control/base/source suites and full regression suite, with native tests launched through `tools/render-cache/test-native.py`. The helper owns a private Xvfb display and the graphics lock, uses Mesa llvmpipe software rendering, and performs native RGBA readback. These checks establish behavior/pixel parity, not hardware performance. No downstream gameplay code is changed.
