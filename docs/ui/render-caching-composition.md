# Content-cache composition

`MGRenderCache` caches only its content paint stage. Wrapper backgrounds, components, overlays and public hooks retain their ordinary positions; content's own component stages and descendant alpha are painted into the target in their original order. The target is composited with white tint and opacity one. Incoming effective opacity other than exactly one bypasses; multiplying a completed bitmap would change overlapping per-primitive alpha.

`MGRenderCache.LastBypassReason` reports the source/context decision at the most recent ordinary `DrawContents` invocation. It performs no notifications, discovery or allocation. A skipped content stage leaves the last value unchanged. `None` means the source and context qualified, **not** that preparation succeeded or a texture was ready. Manager resource/budget/preparation diagnostics remain in `RenderCaches.Statistics.LastBypassReason`. The existing `MGRenderCacheBypassReason` enum is extended without renumbering existing values.

Source diagnostics distinguish empty/disabled content, unknown or unsupported rendering/resources, declared or intrinsic volatility, public callbacks, unresolved layout, unsupported transforms and unbounded painting. Context diagnostics distinguish transform, opacity, viewport, rasterizer, sorting, blending, sampling, depth, caller effects, partial clip and invalid geometry. Finite integer translation and checked screen-coordinate range are required before integer conversion. Context checking and source fact reads remain constant-time.

Normal element clipping can turn a caller's no-scissor rasterizer into `SolidScissorTest`. An internal inherited fact on `ElementDrawArgs` preserves that unsupported caller context through desktop/window/element draw entry, again immediately after live begin-draw callbacks, and `with`-based descendant, scroll, component and preview arguments. Both content and cached-brush operations reject it. It does not alter normal rasterizer/clipping behavior, and capture does not replay user callbacks. No new scene graph walk, input pass, or public callback exemption is introduced.

## Native validation

`CompositionNativeTests` runs the standalone `--composition` lane through `NativeGraphicsHost`. Build and run current source with:

```sh
flock --close /tmp/mgui-render-cache-dotnet.lock dotnet test MGUI.Tests/MGUI.Tests.csproj -c Release --nologo --filter FullyQualifiedName~CompositionNativeTests --logger 'console;verbosity=minimal'
```

The helper owns the graphics lock and its private Xvfb; do not add an outer graphics lock. Evidence uses genuine MonoGame DesktopGL, Release, Mesa 26.2.3 llvmpipe (LLVM 23.1.1) RGBA readback. Software rendering establishes correctness, not hardware FPS.

The `ARTIFACTS:` directory contains a JSON report, assembly SHA256 provenance, full-frame direct/cached PNGs and amplified RGB difference PNGs. Every comparison records differing pixel count, per-channel maxima/counts and first differing pixel. No image regions are masked. Native failures fail xUnit, whose required group and tolerance checks guard report completeness.

The matrix covers all four component stages, backgrounds/self/content/overlay, ordinary siblings before/after the boundary and live wrapper decorations; independent component/content omission controls; descendant translucent overlap over transparent and opaque scenes; incoming boundary and ancestor opacity; integer transform plus nonzero draw offset; full/partial inherited clip and unclipped overflow; ScrollViewer screen-scissor mapping and unchanged clipping bookkeeping during Prepare; layout scales 1/1.5/2, all five scale channels, window overrides and disabled inheritance; unsupported nonunit window/descendant scale, rotation, shear, fractional translation, blends, sampler modes, depth, immediate sorting, wireframe, disabled scissor, viewport and caller effects. NaN/infinite/overflow translations are checked against the native transaction predicate without issuing undefined driver geometry. The active descendant scale test sets the ordinary visual-state setter deterministically, as the interactive fixture does; it is not a physical mouse-input test.

Each public begin/ending/end callback stays live once per normal draw and never executes during preparation. A position-dependent image effect/configuration callback remains unsupported and live. Desktop no-scissor provenance is verified with independently warm content and background-brush entries. Wrapper and ancestor begin callbacks also switch the rasterizer after those entries are warm; both entries must bypass, callbacks remain live, and removing the callback restores both hits. This regression fails before the post-callback provenance check. Unsupported tests check zero new hits and pending requests **before** disabling caching for the direct reference, preventing the reference toggle from hiding a stale observation.

The main → offset/0.25-opacity preview → main test uses the exact draw arguments from `MGWindow`'s drag preview. It requires the next main draw to paint descendants directly, then allows reuse only after a new preparation. An independent fully clipped descendant draw must also retire the prior observed generation and restore live clipping flags on the next main draw.

All comparisons require exact RGBA except the single named `descendant-alpha-opaque-scene` case: RGB may differ by one byte and alpha must be exact. Rendering two translucent layers first into RGBA8 introduces intermediate rounding before blending over the opaque scene. The same layers over transparent clear require exact equality, both layers have independent omission controls exceeding 1,000 changed pixels, and incoming-opacity fallback remains exact. This allowance applies only to this fixed fixture, not arbitrary translucent graphs or effects. The recorded run differs in G/B by one (R/A exact); direct/cached/amplified images are retained for visual review.
