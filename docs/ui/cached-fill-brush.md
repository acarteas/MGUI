# Cached fill brushes

`MGCachedFillBrush` in `MGUI.Core.UI.Brushes.Fill_Brushes` wraps one non-null `IFillBrush`. Caching is enabled by default on this explicit wrapper; ordinary brushes stay unchanged. `Copy()` copies the inner brush and creates independent wrapper, owner, paint-site and target identities.

Use the wrapper directly in an element's background underlay, background fill overlay or `OverlayBrush`. These audited built-in paint sites supply independent identities, including two sites of one owner and shared wrappers on several owners. The public `Draw` method and wrappers nested inside other brush implementations paint directly because those call sites have no stable identity. An outer cached brush may still wrap an arbitrary eligible nested brush graph.

Call `desktop.PrepareRenderCaches()` after the normal desktop update and before clearing or drawing the host scene, outside any active transaction. First use paints the inner brush normally and records its exact bounds, offset, visual state and owner revisions. A later preparation captures that observation; final composition only reads a valid texture. Omitting preparation, changing a generation, detaching an owner or encountering an unsupported context paints the original source with unchanged arguments. Empty bounds do nothing. Targets belong to the desktop's bounded manager; the wrapper never owns or disposes caller textures/effects.

`SourceMode` defaults to `MGRenderCacheSourceMode.Tracked`. Known brush adapters and `IMGRenderCacheSource` provide change-time dependency observations. Unknown sources and effects bypass. `SourceMode=ExplicitlyStatic` asserts that the entire source graph emits bounded, premultiplied, local/UV-only pixels without time, screen-position, interaction, untracked mutable dependencies, side effects or target switches. It admits a static nine-slice/effect graph; it does not override known volatility, disposed resources, cycles or known out-of-bounds painting. An unasserted sibling of the same source remains unsupported.

Call `cachedBrush.InvalidateVisual()` before drawing after effect parameter writes, texture uploads or raw list edits. Observable source changes and `Brush`, `IsCacheEnabled` and `SourceMode` replacements invalidate all live owner/site registrations automatically. Equal assignments do nothing. `InvalidateVisual()` reconciles the source graph without forcing layout. A copied source still shares any textures/effects that its own `Copy()` contract shares, so invalidate each wrapper after opaque shared GPU-resource mutations.

Fractional incoming opacity, partial inherited clipping, nonstandard blend/sampler/depth/sort/rasterizer state, caller effects and unsupported transforms bypass. Original per-layer alpha is preserved. Integer translation and resolved layout UI scale remain eligible through owner/context revisions. `MGElement.IsRenderVolatile` disables reuse without changing update, input or layout; intrinsic running-control volatility cannot be suppressed by setting this explicit flag false. Cached backgrounds do not require the owner's unrelated content painting to be eligible.

T12 validation uses pure source-contract tests and a genuine MonoGame DesktopGL native smoke fixture (`--cached-brush`) covering owner/site isolation, original logical arguments, cold/warm parity, revision/replacement invalidation, partial-clip/opacity fallback, owner volatility recovery, direct-call bypass and disposed-resource rejection. Full layered nine-slice/effect and broader scale/state parity are owned by the subsequent dedicated parity task.

Cache lifetime checks retain the real desktop/device and root attachment while creating and collecting synthetic CPU owners initialized only for registration/snapshots. The fixture measures raw retained weak-list slots across sixteen cohorts, not just live listener counts. Synthetic owners isolate the cache from existing ordinary UI constructor/input retention tracked separately in `mgui-9b9`; they do not establish that ordinary removed windows or children collect. A separate real constructed contextual-content fixture verifies that switching an active child out immediately rejects its pending observation and retires its ready target even while its parent/root links remain unchanged.

Operation invalidation uses one weak dispatcher per owner and per desktop. New registrations and publisher events prune dead operation slots; no idle element-tree traversal is introduced. A removed contributing subtree receives the structural mutation's visual stamp, so its independent cached brushes cannot remain valid solely because their logical parent links survive.
