# Cross-family render invalidation audit

T09 (`mgui-jpa.3.6`) audits the approved [contract](render-caching-design.md) after T06/T07/T08/T30/T31 integration. The inventory below classifies every runtime `MGElement` type present at HEAD `fdbde8d5`, including abstract types and open generic definitions. It is an admission handoff to T18 (`mgui-ch5.2.1`), which owns the runtime exact-type allowlist, maintained eligibility counters and custom opt-in API. Being listed here does not enable caching. Unknown subclasses remain unsupported by default.

## Complete runtime inventory

There are **61 types: 6 abstract and 55 concrete**, including the three open generic definitions. In the table, “candidate” means that the built-in has audited semantic setter, resource and ownership integration; all base clip, transform, incoming opacity, layout, resource lifetime/support, public-hook and volatility requirements still apply. An eligible custom descendant or source requires its own explicit contract. Factory templates are evaluated when creating actual content; generated content is classified by its actual runtime type and sources.

## Every declared paint method

The reflection guard `EveryRuntimeElementTypeAndDeclaredPaintMethodIsInTheReviewedInventory` compares the complete actual assembly type set and the following declared virtual painter set. New types or overridden stages fail the guard until explicitly audited. Inherited stages require no duplicate entry.

| Declared stage | Exact declaring runtime types |
| --- | --- |
| Draw | MGElement; MGWindow (unsupported window protocol); MGTreeViewItem (unsupported post-base arrow). |
| DrawBackground | MGElement; MGSpacer (empty); MGListView<> (header/data regions); MGTabControl (content region); MGGroupBox (header gap); MGOverlayHost (unsupported cross-owner tint). |
| DrawContents | MGElement (empty); MGContentHost (ordinary current children); MGButton (pressed offset); MGScrollViewer (integer offset and mapped screen clip); MGSpacer (empty). |
| DrawSelf | MGElement; MGBorder; MGCheckBox; MGContentPresenter (empty); MGGrid; MGGridColorPicker; MGGridSplitter; MGGroupBox; MGImage; MGListBox<> (base); MGProgressBar; MGProgressButton; MGRadioButton; MGRatingControl; MGRectangle; MGResizeGrip; MGScrollViewer; MGSlider; MGTabControl (empty); MGTabItem (empty); MGTextBlock; MGTextBox; MGUniformGrid. |

Public callback painters and bounded internal ending-stage painters are accounted for in the family coverage docs; reflection of overrides alone would miss them. In particular, wrapped menu arrows, external resize grips and OverlayHost keep honest bypasses rather than hiding their public subscriptions.

## Cross-family evidence

`MGUI.Tests/UI/MGRenderInvalidationAuditTests.cs` adds pure revision tests without constructing fake GraphicsDevice objects or claiming GPU correctness:

- Mixed HUD: text, toggle/button and its border component, image, list/scroll, inherited state and public custom drawing. Each paint-only mutation checks the entire maintained ownership graph: every actual painter/ancestor advances once, unaffected siblings keep all revisions, layout/structure remain unchanged, equal setters and command/metadata changes remain stable. Observable list append changes generated ownership. Shared score/image resources coalesce at the common root; inherited enabled state invalidates its active subtree. Expected HUD membership is asserted explicitly before ownership-path checks so a missing paint edge cannot silently remove a tested painter.
- Inherited foreground advances active contributing text/context only; inactive content and a separate sibling stay stable. Inactive text edits do not dirty the active tree; activation updates structure before use. Raw nested composited-list replacement requires explicit InvalidateVisual, refreshes new source observation without layout and detaches the old source path.
- One hundred alternating detach/reparent cycles mutate the source while detached and attached. Old owners and separate siblings receive no detached-source changes; newly attached source changes reach each current ancestor once and membership stays distinct.
- Balanced 10/100/1,000-node trees are observed once. After warmup, 1,000 validity frames read the public revision triple, immutable snapshot, IsRenderRevisionCurrent and maintained source aggregate facts. Test-only overrides count child discovery and local source enumeration; custom sources count property reads and subscription add/remove. All counts and thread-local allocations must remain zero at every size. A 100-source-change burst advances root exactly 100 times, rejects the old snapshot and settles back to stable reads. There are no wall-time thresholds or production per-hit diagnostic increments.

Native pixel/input/lifetime evidence remains in the already integrated family suites linked above. This audit does not replace those tests or imply that unchanged local pixels can ignore a changed draw context. T18 must combine maintained revisions with its eligibility aggregate and T15/T16 must validate observed geometry, context and generation before any actual target reuse.
